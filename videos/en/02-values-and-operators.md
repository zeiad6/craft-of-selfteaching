# 🎬 Video Script: Chapter 2: Values, Variables, Operators

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Ask Python

**Visual:** The type function called on four values, showing their types.

**Audio:** Don't memorize data types. Ask Python itself with the type function. Integer, float, string and boolean are the basic building blocks.

## Scene 2: Variables

**Visual:** A box with a name label pointing to a value, then the label moves to a new value.

**Audio:** A variable is a name that points to a value. The equals sign here means assignment: make this name point to this value. It is not mathematical equality.

## Scene 3: Operators

**Visual:** A table of arithmetic, comparison and logical operators with colored examples.

**Audio:** A single slash always gives a float, a double slash is floor division, percent is the remainder, and double star is the power. Beware the float trap: zero point one plus zero point two is not exactly zero point three.

## Scene 4: Type Conversion

**Visual:** The string twenty-five converts with int, then a ValueError on a failed conversion.

**Audio:** The input function always returns text. Convert it with int or float. If conversion fails you get a ValueError, so read the message and learn from it.
