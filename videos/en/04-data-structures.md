# 🎬 Video Script: Chapter 4: Data Structures

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Lists and Tuples

**Visual:** A bracketed list being edited, and a parenthesized tuple with a lock icon.

**Audio:** A list is ordered and editable; a tuple is ordered and fixed once created. Choose based on your need.

## Scene 2: Dictionaries

**Visual:** A dict with keys and values, arrows tying each key to its value.

**Audio:** A dictionary maps a key to a value and makes data access fast and clear. Use get to avoid errors when a key is missing.

## Scene 3: Sets

**Visual:** A Venn diagram of two sets showing union, intersection and difference.

**Audio:** A set keeps only unique elements and supports union, intersection and difference. It is the fastest way to remove duplicates.

## Scene 4: Comprehensions

**Visual:** A three-line for loop collapsing into one line.

**Audio:** A list comprehension builds a list in one elegant line. But don't overdo it: if it becomes hard to read, go back to a normal loop.
