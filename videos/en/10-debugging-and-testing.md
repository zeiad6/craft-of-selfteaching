# 🎬 Video Script: Chapter 10: Debugging and Testing

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Exceptions

**Visual:** A try, except, else and finally block in different colors.

**Audio:** Catch the specific errors you expect. Avoid a bare except because it hides real problems.

## Scene 2: Debugging

**Visual:** A logging output with DEBUG and WARNING levels.

**Audio:** In serious projects use logging instead of print. For interactive stepping, put breakpoint in your code.

## Scene 3: Unit Tests

**Visual:** Green tests passing for a leap-year function.

**Audio:** Write a test describing the expected behavior before fixing the bug. Unittest ships with Python, and pytest has simpler syntax.
