# 🎬 Video Script: Preface: Self-Teaching Is a Craft

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Hook

**Visual:** Book title in large type on a dark background, then the question: is learning a talent?

**Audio:** Do you think self-teaching is a talent some people are born with? The truth is simpler. Self-teaching is a craft, and like any craft, anyone can master it with practice.

## Scene 2: Three Illusions

**Visual:** Three cards appear one by one: total readiness, linear learning, fear of errors.

**Audio:** Three illusions keep us from starting. First, that we must be fully ready before the first line of code. Second, that we must understand everything one hundred percent before moving on. Third, fearing error messages, even though they are our most honest teacher.

## Scene 3: The Golden Rule

**Visual:** A code cell prints the Python version when run.

**Audio:** The golden rule of this book: if a paragraph doesn't fully click, run the code and keep moving. The fog lifts by itself once you use a concept in different contexts.

## Scene 4: The Power of Compounding

**Visual:** A chart curving upward exponentially, ending on the number thirty-seven point eight.

**Audio:** If you improve by just one percent every day, after a year you are about thirty-eight times better. Never underestimate small steps. Start today.
