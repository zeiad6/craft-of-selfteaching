# 🎬 Video Script: Chapter 3: Control Flow

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Decisions

**Visual:** A flowchart of a student's score splitting into A, B and C.

**Audio:** A program that makes no decisions is just a calculator. We use if, elif and else, and Python marks blocks by indentation, four spaces, so read carefully.

## Scene 2: Loops

**Visual:** A circular arrow passing over numbers one to five, highlighting break and continue.

**Audio:** A for loop walks through an iterable, and a while loop continues as long as its condition holds. Continue skips the current round, break stops the loop completely.

## Scene 3: Pattern Matching

**Visual:** match and case code handling different commands and showing the result.

**Audio:** Since Python three point ten we have match and case. A clearer alternative to long elif chains, and it can destructure data directly.

## Scene 4: Challenge

**Visual:** The word FizzBuzz in large type counting from one to fifteen.

**Audio:** Time for a challenge. Write FizzBuzz yourself. Print Fizz for multiples of three, Buzz for five, and both for fifteen. Then try the guessing game with binary search.
