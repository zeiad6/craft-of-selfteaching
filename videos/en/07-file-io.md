# 🎬 Video Script: Chapter 7: File I/O

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Memory for Programs

**Visual:** A program closes and its data vanishes, then a file preserves it.

**Audio:** A program that forgets everything when it closes is of limited use. Files give it permanent memory.

## Scene 2: with and pathlib

**Visual:** Code with open and Path reading and writing a file.

**Audio:** Use with to close the file automatically even on errors. Use pathlib to handle paths. And always set the encoding to utf eight, especially for Arabic.

## Scene 3: JSON and CSV

**Visual:** A dict turning into a JSON file, a table turning into CSV.

**Audio:** JSON suits nested data and CSV suits tables. To search folders recursively, use rglob.
