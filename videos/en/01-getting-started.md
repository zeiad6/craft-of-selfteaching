# 🎬 Video Script: Chapter 1: The Art of Careful Reading

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Computers Are Literal

**Visual:** A sentence with a typo a human understands, while the editor shows a red error.

**Audio:** Your brain auto-corrects typos; a computer does not. So the first programming skill is slow, careful reading, symbol by symbol.

## Scene 2: Your First Line

**Visual:** The code: print with a greeting in parentheses, and the output appears below.

**Audio:** The print function shows text on the screen. Any line starting with a hash sign is a comment that the computer ignores; we write it to explain our thinking.

## Scene 3: f-strings

**Visual:** Variables, then a string starting with f with curly braces highlighted.

**Audio:** In modern Python, put an f before the string and write variables inside curly braces. Add an equals sign and Python prints the name along with the value, which is great for debugging.

## Scene 4: Reading Errors

**Visual:** A NameError with the hint Did you mean print, last line highlighted.

**Audio:** When an error appears, don't panic. Read the last line first. Modern Python pinpoints the problem and sometimes suggests the fix. An error is not failure; it is information.
