# 🎬 Video Script: Chapter 11: Reading the Documentation

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Ask the Interpreter

**Visual:** dir, help and signature showing information about str.

**Audio:** Before searching the web, ask Python. Dir shows what you can do, help explains how, and type tells you what the object is.

## Scene 2: Signature Anatomy

**Visual:** The sorted signature with the slash and star highlighted.

**Audio:** The slash means everything before it is positional-only, and the star means everything after is keyword-only. That's how you know why some calls work and others fail.

## Scene 3: The Docs Site

**Visual:** The docs.python.org page with Tutorial, Library Reference and What's New.

**Audio:** Read the first paragraph, then the examples, then the parameters, and finally the version notes. Whoever can read the docs never needs a teacher again.
