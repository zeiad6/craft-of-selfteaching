# 🎬 Video Script: Chapter 6: Strings and Regex

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Strings

**Visual:** Arabic and English text passing through strip, split and join.

**Audio:** Python strings support full Unicode, so Arabic just works. Strings are immutable, so every method returns a new string.

## Scene 2: Formatting

**Visual:** Number formatting examples: two decimals, thousands separators, percentage.

**Audio:** Inside an f-string you control the format. Dot two f for two decimals, a comma for thousands, and a percent sign for percentages.

## Scene 3: Regular Expressions

**Visual:** An email address highlighted piece by piece according to the pattern.

**Audio:** A regular expression is a mini-language describing text patterns. Use a raw string so backslashes survive, and try findall, search and sub.

## Scene 4: Challenge

**Visual:** A password field switching between red and green.

**Audio:** Today's challenge: validate password strength with one regex. At least eight characters, an uppercase letter, a lowercase letter, and a digit.
