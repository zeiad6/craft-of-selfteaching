# 🎬 Video Script: Chapter 8: Object-Oriented Programming

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Blueprint and Object

**Visual:** A house blueprint becoming several real houses.

**Audio:** A class is a blueprint and an object is a real thing built from it. The init method runs on creation, and self refers to the object itself.

## Scene 2: Inheritance

**Visual:** A tree: Shape on top with Square and Circle beneath.

**Audio:** Inheritance lets a subclass inherit from a parent. Polymorphism means calling the same method and having each class respond in its own way.

## Scene 3: Dataclasses

**Visual:** Ten lines of code shrinking to three thanks to dataclass.

**Audio:** The dataclass decorator generates construction, printing and comparison automatically. Use it whenever you need a class that just holds data.
