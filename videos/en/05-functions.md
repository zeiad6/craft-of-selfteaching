# 🎬 Video Script: Chapter 5: Functions

> Note: Audio text has no code symbols or emoji so Edge-TTS reads it naturally. See `../README.md` for the production workflow.

## Scene 1: Why Functions

**Visual:** A big problem splitting into small cubes, each cube a function.

**Audio:** A function lets you split a big problem into small parts that are easy to understand, test and reuse. This is problem decomposition.

## Scene 2: Defining

**Visual:** A def with type hints and a docstring, arrows labeling each part.

**Audio:** Define a function with def, add type hints, and document it with a short string at the top. Then call it by position or by name.

## Scene 3: Flexible Parameters

**Visual:** A single star gathering values into a tuple, a double star gathering names into a dict.

**Audio:** Star args collects positional arguments, double-star kwargs collects named ones. Variables inside a function are local and don't leak out.

## Scene 4: Generators

**Visual:** The word yield producing numbers one by one instead of a whole list.

**Audio:** A generator produces values on demand instead of building a huge list in memory. Use yield to build one, and try the infinite Fibonacci.
