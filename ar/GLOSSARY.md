# 📖 مسرد المصطلحات التقنية المعتمدة (Technical Glossary)

يهدف هذا المسرد إلى توحيد المصطلحات البرمجية والتقنية عبر جميع فصول النسخة العربية من كتاب **"فن التعلّم الذاتي" (The Craft of Self-Teaching)**.

> **قاعدة التعريب في الكتاب:** نكتب المصطلح العربي الواضح والسلس، متبوعاً بالمصطلح الإنجليزي بين قوسين عند ذكره لأول مرة في الفصل، ليتمكّن القارئ من الفهم العميق باللغة العربية والبحث الاحترافي باللغة الإنجليزية في التوثيقات الرسمية وسوق العمل.

---

## 1️⃣ مفاهيم التعلّم والمنطق العام (Learning & General Logic)

| المصطلح الإنجليزي (English Term) | المصطلح العربي المعتمد | ملاحظات وسياق الاستخدام |
| :--- | :--- | :--- |
| **Self-Teaching / Autodidacticism** | التعلّم الذاتي | المهارة الأساسية التي يدور حولها الكتاب |
| **Meta-skill / Meta-learning** | مهارة ما وراء التعلّم / المهارة الأم | المهارة التي تمكّنك من اكتساب أي مهارة أخرى |
| **Entry Barrier** | حاجز الدخول | الصعوبات النفسية والتقنية في بداية تعلّم مجال جديد |
| **Deliberate Practice** | الممارسة المتعمّدة / التدريب الواعي | التدريب المركّز الهادف لتحسين نقاط الضعف |
| **Abstraction** | التجريد | إخفاء التفاصيل المعقدة والتركيز على الجوهر |
| **Decomposition** | تفكيك المشكلات | تقسيم المشكلة الكبيرة إلى أجزاء صغيرة قابلة للحل |
| **Algorithm** | خوارزمية | خطوات منطقية متسلسلة لحل مشكلة معينة |
| **Syntax** | بناء الجملة / القواعد النحوية للغة | القواعد التي تحدد كيف تُكتب أوامر اللغة البرمجية |
| **Semantics** | الدلالة المنطقية / المعنى | ما يفعله الكود فعلياً عند تشغيله |

## 2️⃣ أساسيات بايثون والبيانات (Python Basics & Data Types)

| المصطلح الإنجليزي (English Term) | المصطلح العربي المعتمد | ملاحظات وسياق الاستخدام |
| :--- | :--- | :--- |
| **Variable** | متغيّر | اسم يشير إلى قيمة مخزنة في الذاكرة |
| **Constant** | ثابت | قيمة لا يُفترض تغييرها أثناء تشغيل البرنامج |
| **Value / Literal** | قيمة / قيمة مجرّدة | البيانات نفسها مثل `42` أو `"Hello"` |
| **Data Type** | نوع البيانات | تصنيف القيمة (`int`, `float`, `str`, `bool`) |
| **Type Hints / Annotations** | تلميحات الأنواع | ميزة حديثة لتوضيح أنواع المتغيرات والدوال في Python |
| **Expression** | تعبير برمجي | أي جزء من الكود يُقيَّم وينتج قيمة |
| **Statement** | جملة برمجية / تعليمة | أمر كامل ينفّذه مفسّر بايثون |
| **Operator** | مُعامِل / عامل تشغيل | مثل المعاملات الحسابية (`+`, `-`) أو المنطقية (`and`, `or`) |
| **Operand** | مُعامَل | القيمة التي يعمل عليها المُعامِل |
| **Boolean** | قيمة منطقية | قيمة تحتمل الصواب (`True`) أو الخطأ (`False`) فقط |
| **String Interpolation / f-strings** | النصوص المنسّقة (`f-strings`) | دمج المتغيرات والتعبيرات مباشرة داخل النصوص |

---

## 3️⃣ التحكّم في التدفق وهياكل البيانات (Control Flow & Data Structures)

| المصطلح الإنجليزي (English Term) | المصطلح العربي المعتمد | ملاحظات وسياق الاستخدام |
| :--- | :--- | :--- |
| **Control Flow** | التحكّم في التدفق | توجيه مسار تنفيذ البرنامج (شروط، حلقات تكرار) |
| **Conditional Statement** | جملة شرطية | `if` / `elif` / `else` |
| **Structural Pattern Matching** | مطابقة الأنماط الهيكلية | جملة `match / case` الحديثة في Python 3.10+ |
| **Loop / Iteration** | حلقة تكرار / تكرار | تنفيذ كتلة برمجية عدة مرات (`for`, `while`) |
| **Iterable** | كائن قابل للتكرار | أي هيكل بيانات يمكن المرور على عناصره واحداً تلو الآخر |
| **Iterator** | مُكرِّر | كائن ينتج العناصر واحداً تلو الآخر عند الطلب |
| **Generator** | مُولِّد | دالة تنتج سلسلة من القيم كسولياً (Lazily) باستخدام `yield` |
| **List** | قائمة | هيكل بيانات مرتب وقابل للتعديل `[]` |
| **Tuple** | صفّ (Tuple) | هيكل بيانات مرتب وغير قابل للتعديل `()` |
| **Dictionary (`dict`)** | قاموس | هيكل بيانات يربط المفاتيح بالقيم (Key-Value Pairs) `{}` |
| **Set** | مجموعة | تشكيلة غير مرتبة من العناصر الفريدة غير المكررة |
| **List Comprehension** | القوائم المختصرة / الإدراكية | صياغة مختصرة وأنيقة لإنشاء القوائم في سطر واحد |
| **Mutable vs. Immutable** | قابل للتعديل مقابل غير قابل للتعديل | قدرة الكائن على تغيير محتواه بعد إنشائه |

## 4️⃣ الدوال والبرمجة كائنية التوجه (Functions & OOP)

| المصطلح الإنجليزي (English Term) | المصطلح العربي المعتمد | ملاحظات وسياق الاستخدام |
| :--- | :--- | :--- |
| **Function** | دالة | كتلة برمجية قابلة لإعادة الاستخدام تؤدي مهمة محددة |
| **Parameter vs. Argument** | مُعامِل تعريفي (Parameter) مقابل مُعطى تمريري (Argument) | المتغير في تعريف الدالة مقابل القيمة الفعلية الممررة لها |
| **Return Value** | القيمة المُرجعة | النتيجة التي تعيدها الدالة بعد انتهاء تنفيذها |
| **Scope** | النطاق | المجال الذي يكون فيه المتغير مرئياً وقابلاً للوصول |
| **Lambda / Anonymous Function** | دالة مجهولة (`lambda`) | دالة صغيرة سطرية بدون اسم رسمي |
| **Decorator** | مُزخرِف (Decorator) | دالة تعدّل أو توسّع سلوك دالة أخرى (`@decorator`) |
| **Object-Oriented Programming (OOP)** | البرمجة كائنية التوجه | نمط برمجي ينظّم الكود حول الكائنات والبيانات |
| **Class** | فئة / صنف (Class) | القالب أو المخطط الهندسي الذي تُنشأ منه الكائنات |
| **Object / Instance** | كائن / نسخة كائنية (Instance) | عنصر فعلي تم إنشاؤه بناءً على فئة معينة |
| **Attribute / Property** | سِمة / خاصية | متغير مرتبط بكائن أو فئة |
| **Method** | دالة تابعة / طريقة (Method) | دالة معرّفة داخل فئة وتعمل على كائناتها |
| **Inheritance** | الوراثة | اكتساب فئة فرعية لخصائص وطرق فئة أبوية |
| **Encapsulation** | التغليف | جمع البيانات والطرق معاً وتقييد الوصول المباشر لبعض الأجزاء |
| **Polymorphism** | تعدّد الأشكال | قدرة كائنات مختلفة على الاستجابة لنفس اسم الدالة بطريقتها الخاصة |
| **Dataclass** | فئة بيانات (`@dataclass`) | أداة حديثة في بايثون لإنشاء فئات مخصصة لتخزين البيانات بأقل كود ممكن |

## 5️⃣ البيئة البرمجية، الأخطاء، والاختبارات (Tooling, Debugging & Testing)

| المصطلح الإنجليزي (English Term) | المصطلح العربي المعتمد | ملاحظات وسياق الاستخدام |
| :--- | :--- | :--- |
| **Module** | وحدة برمجية | ملف بايثون (`.py`) يحتوي على دوال وفئات قابلة للاستيراد |
| **Package / Library** | حزمة / مكتبة برمجية | مجموعة من الوحدات البرمجية المنظمة في مجلد |
| **Virtual Environment (`venv`)** | بيئة افتراضية | مساحة معزولة لتثبيت مكتبات مشروع معين دون التأثير على النظام |
| **Exception** | استثناء (خطأ تشغيلي) | حدث غير طبيعي يقع أثناء التشغيل ويمكن التقاطه ومعالجته |
| **Traceback / Stack Trace** | تتبّع مسار الخطأ (Traceback) | التقرير التفصيلي الذي يوضّح أين ولماذا حدث الخطأ |
| **Debugging** | تنقيح الأخطاء (Debugging) | عملية اكتشاف وتحليل وإصلاح العلل البرمجية |
| **Unit Testing** | اختبار الوحدات | التحقق الآلي من صحة أجزاء صغيرة ومستقلة من الكود |
| **Official Documentation** | التوثيق الرسمي | المرجع الأساسي المعتمد لأي لغة أو مكتبة برمجية |
