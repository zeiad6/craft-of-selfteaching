## 🧩 مشاريع مصغّرة مقترحة
1. **عدّاد كلمات** لملف نصي مع تقرير أكثر 10 كلمات.
2. **مولّد كلمات مرور** آمن باستخدام الوحدة `secrets`.
3. **محوّل ملفات** من CSV إلى JSON وبالعكس.
4. **مُنظِّم ملفات** يرتب مجلد التنزيلات حسب الامتداد.
5. **لعبة خمّن الرقم** مع تسجيل أفضل النتائج في ملف.
